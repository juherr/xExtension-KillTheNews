## 0.1.0 - 2026-05-24

- Initial FreshRSS extension for creating kill-the-news newsletter addresses.
- Configuration for instance URL, API token, TLS verification, and connection testing.
- Add-subscription panel with newsletter creation, copy support, and existing address listing.
- PHPUnit coverage for the framework-free kill-the-news API client.
