# Changelog

All notable changes to this project will be documented in this file.

## 0.1.1 - 2026-05-24

### Changed

- Integrate kill-the-news as a FreshRSS feed source type in the add-subscription form.
- Fill the generated feed URL and newsletter email directly in the FreshRSS UI.
- Show the newsletter email and kill-the-news management link on FreshRSS feed details.

## 0.1.0 - 2026-05-24

### Added

- Initial FreshRSS extension for creating kill-the-news newsletter addresses.
- Configuration for instance URL, API token, TLS verification, and connection testing.
- Add-subscription panel with newsletter creation, copy support, and existing address listing.
- PHPUnit coverage for the framework-free kill-the-news API client.
